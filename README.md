# おうちの家計簿 🐻🐰🐥💕

かぞくみんなで、にこにこ家計管理ができる **かわいい家計簿アプリ** です。
紙の家計簿（月のまとめ・収入・支出・生活費・クレジットカード利用控え・特別支出）を、
そのままやさしい雰囲気のWebアプリにしました。

## ✨ できること

- 📅 **月ごとに管理** … 矢印か月ピッカーで前月・翌月にきりかえ
- 🌸 **収入** … くりこし・給与など（項目は自由にふやせる）
- 🏠 **固定費** … 電気・ガス・水道・電話・携帯・ネット・住居・貯蓄・保険
- 🍓 **生活費** … 食費・日用品など
- 💳 **クレジットカード利用控え** … 月日・品名・購入先・金額・カード名・支払済チェック
- 🎁 **特別支出** … 月日・内容・金額
- 💰 **残高（来月へのくりこし）を自動計算**
- 🐽 **貯金ぶたメーター** … 貯蓄率にあわせてぶたさんが応援コメント
- 📝 **メモ** … 今月のひとこと
- 💾 **自動保存** … ブラウザの localStorage に保存（インストール不要）

## 🚀 使い方

特別な準備はいりません。ブラウザで開くだけです。

```
# このフォルダで index.html を開くだけ
open index.html        # macOS
# または、かんたんなローカルサーバーで
python3 -m http.server 8000   # → http://localhost:8000
```

## 🛠 技術

- 素の HTML / CSS / JavaScript（フレームワーク・ビルド不要）
- データはブラウザの `localStorage` に保存（このブラウザ内だけに残ります）

| ファイル | 役割 |
