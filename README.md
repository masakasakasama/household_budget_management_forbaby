# おうちの家計簿 🐻🐰🐥💕

かわいいパステルの **家計簿Webアプリ**。
紙の家計簿（月のまとめ・収入・支出・生活費・クレジットカード利用控え・特別支出）を、
そのままやさしい雰囲気のWebアプリにしました。インストール不要・無料・APIキー不要。

## ✨ できること

- 📅 **月ごとに管理** … 矢印か月ピッカーで前月・翌月にきりかえ
- 🌸 **収入** … くりこし・給与など（項目は自由に追加／▲▼で並べ替え）
- 🏠 **固定費** … 電気・ガス・水道・電話・携帯・ネット・住居・貯蓄・保険
- 🍓 **生活費** … 食費・日用品など
- 💳 **クレジットカード利用控え** … 月日・品名・購入先・金額・カード名・支払済チェック
- 🎁 **特別支出** … 月日・内容・金額
- 💰 **残高（来月へのくりこし）を自動計算**
- 🐽 **貯金ぶたメーター** … 貯蓄率にあわせてぶたさんが応援コメント
- 📝 **メモ** … 今月のひとこと
- 🔄 **複数デバイス同期** … リンクを共有すれば、スマホ・PC・タブレットで同じ家計簿
- 📴 **オフラインでも安心** … 通信できない時は最後に成功したデータを表示
- 💾 **自動保存** … localStorageキャッシュ＋クラウド同期

## 🔗 共有リンク（複数デバイスで使う）

1. アプリ上部の **「🔗 端末を同期」** を押すと、共有リンクと「おうちコード」が発行されます。
2. その **リンクを別の端末で開く**（`?ouchi=<コード>` 付きURL）と、同じ家計簿が同期されます。
3. リンクが使えない時は、別端末で **「🏠 参加」** を押して **おうちコード** を入力してもOK。
4. 起動時・15秒ごと・タブに戻った時・編集時に自動同期。手動更新は **「🔄 更新」**。

> 同期は無料サービス [jsonblob.com](https://jsonblob.com) を利用（認証・APIキー不要）。
> データは各端末の localStorage にもキャッシュされ、オフライン時はそれを表示します。

## 🚀 使い方（ローカル）

特別な準備はいりません。ブラウザで開くだけです。

```
open index.html               # macOS（ファイルを直接開く）
python3 -m http.server 8000   # → http://localhost:8000
```

## 🛠 技術

- 素の HTML / CSS / JavaScript（フレームワーク・ビルド不要）
- 保存：ブラウザの `localStorage`（オフラインキャッシュ）
- 同期：jsonblob.com（無料・認証不要のJSONストレージ）

## ⚠️ 制限事項

- 同期は **last-write-wins**。2端末で同時刻に別々の編集をすると、後から保存した方で上書きされる場合があります（家計簿用途では実用上ほぼ問題なし）。
- jsonblob のブロブは **75日間アクセスが無いと削除** されます（通常利用なら問題なし。各端末のキャッシュは残ります）。
- **Androidアプリ / ホーム画面ウィジェットは未対応**（現状はWebアプリ）。今後の対応候補です。
- デザインは「かわいい」優先のため、別途の黒背景・iOS風要件は本アプリでは不採用です。
